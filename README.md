# AI-Powered Fake News Detection Using Text Classification

A complete text-classification pipeline that labels a news article `REAL` or `FAKE`.
Every component — tokeniser, stemmer, Bag-of-Words, TF-IDF, LSA embeddings, all four
classifiers and the full metric suite — is implemented **from scratch in NumPy**, as the
brief requires. scikit-learn appears only in the final verification section, as an
independent check that the hand-written mathematics is correct.

---

## Results

Measured on a held-out stratified 20% test set (1213 articles) of a public labelled corpus of 6060 news articles. Seed 42.

| Model | Accuracy | Precision | Recall | F1 | ROC AUC | Fit (s) |
|---|---|---|---|---|---|---|
| K-Nearest Neighbours | 0.8697 | 0.9224 | 0.8114 | 0.8633 | 0.9526 | 0.05 |
| Logistic Regression | 0.9134 | 0.9009 | 0.9317 | 0.9161 | 0.9746 | 27.4 |
| Random Forest | 0.8335 | 0.8068 | 0.8829 | 0.8432 | 0.9116 | 39.8 |
| **Neural Network** | **0.9167** | 0.9066 | 0.9317 | **0.9190** | 0.9728 | 1.2 |

5-fold cross-validated F1: **0.9193 ± 0.0083**

Verification against scikit-learn on identical features and splits:

| Model | From scratch | scikit-learn | Difference |
|---|---|---|---|
| K-Nearest Neighbours | 0.8697 | 0.8689 | 0.0008 |
| Logistic Regression | 0.9134 | 0.9143 | 0.0008 |
| Random Forest | 0.8335 | 0.8516 | 0.0181 |
| Neural Network | 0.9167 | 0.9085 | 0.0082 |

The random-forest gap is expected: the from-scratch tree searches quantile candidate
thresholds rather than every unique value, a deliberate trade of a little accuracy for
roughly an order of magnitude in fit time.

## Quick start

```bash
pip install -r requirements.txt
python download_dataset.py     # fetches the real corpus used for the reported results
python main.py                 # ~2 min; writes results/
```

**No network?** Skip the download. `main.py` falls back to `data/news_dataset.csv`, the
synthetic corpus bundled with this project, and every stage runs unchanged — only the
numbers differ (see the note below on why the synthetic corpus is *harder*).

The real corpus is not bundled because the raw CSV is ~30 MB, which would push this
archive past the upload limit. `download_dataset.py` restores the exact file the results
were measured on and prints the row counts so you can confirm you have the same revision.

Or open the notebook, which contains the same pipeline with narrative and embedded
outputs already executed:

```bash
jupyter notebook Fake_News_Detection.ipynb
```

## Using a different corpus

The loader prefers `data/train.csv` when present and falls back to the bundled synthetic
corpus otherwise. To substitute your own data (the Kaggle *Fake and Real News* set, the
UCI collection, or anything else), save it as `data/train.csv` with a `text` column and a
`label` column — either `0`/`1` or the strings `REAL`/`FAKE`, both are handled — and re-run
`python main.py`. Nothing downstream changes.

## About the bundled dataset

`data/news_dataset.csv` is generated by `generate_sample_dataset.py` so the pipeline runs
offline and every figure in the report reproduces exactly.

It is built deliberately **hard**. A generator that draws real articles only from a
factual word list and fake articles only from a sensational one produces perfectly
separable classes, and every classifier then scores 1.00 — a result that measures
nothing. Instead each document receives a hidden leaning θ ~ Beta(0.7, 0.7); sentences
are drawn from the fabricated pool with probability θ and the factual pool otherwise,
with a fifth drawn from a neutral pool shared by both classes. The label is `1[θ > 0.5]`,
so documents near θ = 0.5 are genuinely ambiguous. A 3% label-flip rate simulates
annotation error.

## Key findings

- **The top two models are tied, not ranked.** The neural network's lead over logistic
  regression is 0.33 points — about four test articles, well inside the fold-to-fold
  spread of the cross-validation.
- **The representation mattered more than the classifier.** The network trains on 150
  dense LSA dimensions rather than 3,000 sparse ones. That compression denoises the input
  and is also why it fits in 1.2 s while logistic regression needs 27 s on the full
  sparse matrix. On the smaller synthetic corpus the same architecture could not beat the
  linear model at all.
- **The random forest trailed by eight points.** Axis-aligned splits ask whether one
  term's weight exceeds a threshold, and any single term is a weak, noisy indicator. That
  gap is far too large to be noise.
- **Cost and accuracy rank the four families completely differently.** The most accurate
  model was also among the cheapest to fit; KNN is the mirror image, free to train and
  slowest to query.

## The most important result is negative

Reading the logistic-regression coefficients (notebook §7, report §V-D) shows the
strongest "FAKE" indicators are **october, november, article, hillary, us, election** and
the strongest "REAL" ones **said, republican, say, tuesday, obama, cruz**.

Almost none of that is a cue of deception. Month names and recurring political surnames
mark *when* an article was written and *what* it was about. Corpora like this one are
assembled by scraping real articles from mainstream outlets over one window and
fabricated ones from a different set of sites, often over a different window — so
provenance correlates with the label, and a discriminative model will take that shortcut.

Two consequences follow directly: the model will degrade sharply on articles from a later
period, and it is trivially evadable by avoiding the flagged vocabulary without writing
any more honestly. **Neither failure is visible anywhere in the results table.** The
synthetic corpus, where topic is drawn independently of the label, scores several points
lower — and that drop is a rough estimate of how much of the 91.7% is provenance rather
than deception.

## Limitations

- A substantial part of the reported accuracy comes from topical and temporal artefacts of
  the corpus rather than from cues of deception. The figure should not be read as a measure
  of real-world detection ability.
- The corpus is drawn from a single period and a single political context.
- Evasion is cheap: avoiding the flagged vocabulary defeats the classifier.
- Bag-of-words features discard word order and context entirely.
- English-only, and no source reputation, publication metadata or propagation signal.
- A single held-out split with cross-validation on the training partition; a
  repeated-splits protocol would give tighter confidence intervals.
